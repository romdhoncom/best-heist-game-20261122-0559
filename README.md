# The Midnight Vault

A top-down heist game for the make.fun bounty "Make the best heist game". You are a thief crossing a bank vault room at night: stay out of the guards' yellow vision cones and the security cameras' blue sweeps, hack the camera panels, grab the loot, and slip out the green door before the alarm meter hits 100%.

- Guards patrol with wall-clipped vision cones; suspicion fills, then they chase.
- Security cameras sweep blue cones and raise the alarm fast; hack their panels (hold E) to kill them.
- An alarm meter (0–100%): at 100% every guard converges and the exit locks for 10 seconds.
- Sneak (Shift) to halve your detection range; hide in shadow zones; desks block sight.
- 3 levels — The Gallery, The Vault, The Penthouse (with laser grids) — 3 lives, stars and score.

Play it: serve `game/` with any static server and open `game/index.html` in desktop Chrome. Move WASD / arrows, sneak Shift, hack / interact E, M mute, Esc pause, R restart. All art is drawn in code and all sound is synthesised WebAudio; the game makes no network requests.
